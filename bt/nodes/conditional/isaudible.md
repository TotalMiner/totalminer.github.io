# (Official) Behavior Tree Documentation

## IsAudible

Check if a sound occured within range of the target actor.

___
## Parameters

- `Distance`: The max distance to check from the NPC's position.
- `SoundTypes`: The type of action that caused the sound.
- `Continue`: When set true the node will always succeed.
- `IsEnabled`: When set false the node will always fail.
- `Comment`: User comments.
