# (Official) Behavior Tree Documentation

## IsWithinRadius

Check if the target NPC is within a certain distance.

___
## Parameters

- `RefindTime`: The time between checking for potential targets.
- `Distance`: The max distance an NPC can be from the target actor.
- `Continue`: When set true the node will always succeed.
- `IsEnabled`: When set false the node will always fail.
- `Comment`: User comments.
