# (Official) Behavior Tree Documentation

## IsEquipType

Check the held item of the target actor.

___
## Parameters

- `Target`: Sets if the comparison is applied to the NPC or the NPC's target.
- `Hand`: Which hand to check.
- `Item`: The specific item to check for.
- `Type`: The item type to check for.
- `SubType`: The item subtype to check for.
- `Class`: The item class to check for.
- `Continue`: When set true the node will always succeed.
- `IsEnabled`: When set false the node will always fail.
- `Comment`: User comments.
