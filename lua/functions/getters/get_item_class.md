
# (Official) LUA Scripting Documentation

## get_item_class

Get the class of the specified item.

___

Spec:

```lua
get_item_class()
```

## Returns

- `string`: The item class. Returns N/A if the item is invalid.

___

## Example

```lua
print(get_item_type(item.camera)
```

This will print the Camera class which is CantMine.
